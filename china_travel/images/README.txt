Drop your own photos here and the Cities page will use them automatically.
Naming (city id -> file):
  images/wangxian.jpg   -> Wangxian Valley card
  images/dalian.jpg     -> Dalian card
You can also add others, e.g. images/shenzhen.jpg, images/chongqing.jpg …
The default web photo is used until the matching file exists here.
